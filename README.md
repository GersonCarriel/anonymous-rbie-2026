# anonymous-rbie-2026

Este repositório reúne artefatos, documentação e materiais suplementares associados ao manuscrito submetido à RBIE.

## Objetivo

O repositório disponibiliza materiais relacionados à ferramenta educacional adaptativa apresentada no manuscrito, incluindo recursos utilizados na experiência, instrumentos de coleta de dados e artefatos técnicos necessários para apoiar a avaliação e a reprodutibilidade do estudo.

## Conteúdo

* Documentação técnica
* Exemplos da integração LTI
* Estruturas do modelo conceitual
* Exemplos de visualizações
* Materiais do curso experimental
* Instrumentos de coleta de dados
* Dados anonimizados e recursos complementares

## Observação

Informações que possam identificar autores, instituições ou o nome original da ferramenta foram removidas ou substituídas para preservar o anonimato durante o processo de revisão por pares.
